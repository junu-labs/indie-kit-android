# indie-kit-android

Android 공용 모듈 (광고, 로그인, 결제, 통계).

`indie-kit` 의 13명 시스템으로 만들어진 Android 앱들이 공통으로 가져다 쓰는 부품 묶음.

## 폴더 위치

```
~/Developer/JunuLabs/System/indie-kit-android/
```

## 안에 들어갈 것 (앞으로)

- 광고 (AdMob 연결)
- 로그인 (Google / Apple)
- 결제 (Google Play Billing)
- 통계 (사용 기록)

지금은 자리만 잡아 두었다. 모듈은 필요할 때 한 개씩 들어온다.
